Errore: "arm-linux-gnueabihf-gcc: command not found"
→ Soluzione: Usa il nome completo del compilatore nel tuo toolchain

  Trova il compilatore:
    $ ls /opt/*/bin/*gcc* | head -5
  
  Compila specificando il compilatore:
    $ make platform=miyoomini CC=arm-buildroot-linux-gnueabihf-gcc \
           CXX=arm-buildroot-linux-gnueabihf-g++ \
           AR=arm-buildroot-linux-gnueabihf-ar

Errore: "undefined reference to vld1_u8"
→ Soluzione: Verifica flag NEON
    $ make platform=miyoomini V=1 | grep mfpu
    # Deve contenere: -mfpu=neon-vfpv4

Core troppo grande (> 2MB)
→ Soluzione: Strip dei debug symbols
    $ strip cap32_libretro.so
